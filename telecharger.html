Télécharger l'application

Fichier taxi-pro.apk, pour téléphone Android uniquement.

AIDE À L'INSTALLATION

Comment l'installer

  1. Touchez le bouton jaune ci-dessus. Si Chrome demande de confirmer le téléchargement, acceptez.
  2. Ouvrez le fichier téléchargé (notification « Téléchargement terminé », ou application « Fichiers », dossier « Téléchargements »).
  3. Android peut dire que l'installation depuis cette source est bloquée : touchez « Paramètres » et autorisez, puis revenez en arrière et touchez « Installer ».
  4. Si un message dit « application non vérifiée » ou propose une analyse, choisissez « Installer quand même ». C'est normal : l'application ne vient pas du Play Store.
  5. À la première ouverture, autorisez la localisation sur « Toujours autoriser » et acceptez les notifications. Cela permet au suivi GPS de continuer écran éteint.

Pour que le suivi GPS ne s'arrête pas

  1. Réglages du téléphone, Applications, Taxi Pro, Batterie : choisissez « Aucune restriction ».
  2. Sur Xiaomi, activez aussi le « Démarrage automatique » pour Taxi Pro.

Vos données restent uniquement sur votre téléphone. Pour les déplacer vers un autre téléphone, utilisez « Exporter la sauvegarde » puis « Restaurer » dans les Réglages de l'application.

Si le bouton ne télécharge rien, ouvrez cette page directement dans Chrome (et non dans une application de messagerie).
